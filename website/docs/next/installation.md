# Installation

Requires Next.js 15 or 16, React 18 or 19, and Node.js 22.12 or later. The guides and examples use the App Router. The package ships ES modules only, and its types need TypeScript 5.9 or later.

You can install either the standard package or an alias package for shorter imports.

### Standard Package

```bash
npm install @i18n-tiny/next
# or
pnpm add @i18n-tiny/next
# or
yarn add @i18n-tiny/next
```

### Alias Package

You can use `next-i18n-tiny` as an alias for `@i18n-tiny/next`. It has the same version and the same features.

```bash
npm install next-i18n-tiny
# or
pnpm add next-i18n-tiny
# or
yarn add next-i18n-tiny
```
