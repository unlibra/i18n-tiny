# Installation

Requires React 18 or 19, and Node.js 22.12 or later when it runs on Node.js (for example in server rendering or tests). The package ships ES modules only, and its types need TypeScript 5.9 or later.

You can install either the standard package or an alias package for shorter imports.

### Standard Package

```bash
npm install @i18n-tiny/react
# or
pnpm add @i18n-tiny/react
# or
yarn add @i18n-tiny/react
```

### Alias Package

You can use `react-i18n-tiny` as an alias for `@i18n-tiny/react`. It has the same version and the same features.

```bash
npm install react-i18n-tiny
# or
pnpm add react-i18n-tiny
# or
yarn add react-i18n-tiny
```
